This project is a fully integrated GUI-based chess game developed in Java.
It combines backend chess logic with a Swing-based graphical interface.

Full chess board GUI (8x8)
Complete piece set:
Pawn, Rook, Knight, Bishop, Queen, King
Legal move validation per piece
Turn-based system (White / Black)
Capture mechanics
Undo move system
MVC-style separation (GUI + backend logic)
